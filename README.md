# Git-Module

A beginner-friendly repository for learning Git and GitHub through practical examples.

## 📌 About

This repository contains simple Python functions and tests created while learning Git and GitHub workflows.

## 🛠️ Technologies

* Python
* Git
* GitHub
* Pytest

## 📂 Project Structure

```text
Git-Module-/
├── app.py
├── tests/
│   └── test_app.py
└── README.md
```

## ✨ Features

* Add two numbers
* Multiply two numbers
* Subtract two numbers
* Divide two numbers
* Handle division by zero
* Basic automated tests with Pytest

## 🧪 Run Tests

Install pytest if required:

```bash
pip install pytest
```

Run the tests:

```bash
py -m pytest
```
